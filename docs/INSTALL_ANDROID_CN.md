# 📱 安装 · Android Firefox Mobile Beta v0.3.0

**支持：** Android 手机 / 平板上的 Firefox 浏览器 + Tampermonkey，访问 `chatgpt.com`。这是网页用户脚本，**无法在 ChatGPT 安卓官方 App 内运行**。桌面 Chrome 请使用独立 [桌面版](INSTALL_CN.md)。

## 安装与启动

1. 在 Android Firefox 的「扩展」中安装并启用 Tampermonkey。扩展可用性请以 Firefox 当前扩展商店为准。
2. 打开 [手机版源码](../dist/chatgpt-duo-skin-android.user.js)，复制全部内容。Tampermonkey → 创建新脚本 → 全选替换模板 → 粘贴并保存。若浏览器弹出直接安装提示，也可以从源码页安装。
3. **只启用一份** Duo Skin 手机版；关闭旧的私人版本及同类脚本，防止重复状态卡。用 Firefox 重新打开 `https://chatgpt.com/`。
4. 在聊天页点击可拖动的小土星 →「主题工坊」，设置两个人的昵称、头像、渐变、壁纸和可选纪念日。

> 第一次安装会看到中性头像，AI / 用户的默认昵称是通用值。**源码不包含作者的照片、私密状态或私人纪念日**，也不会自动读取任何私人脚本存储。

## 手机版功能

- **双人状态卡：** AI 左、用户右；按可见消息装饰，时间是浏览器首次观察到该条消息的时间快照，不是假定的发送时间。
- **移动消息间距：** 对 `display:contents` 的旧 DOM 包装使用安全占位槽，避免卡片和消息重复留白；不同 ChatGPT 网页版本仍可能需要适配。
- **主题面板：** 小土星触控展开，支持半屏 / 扩展 / 收起；面板内部可滚动，移动键盘弹出时尽量避让。
- **无级配色：** 点击六个颜色按钮打开连续 HSV 色相 + 明暗饱和度面板，也可输入十六进制 HEX。
- **壁纸：** 仅绘制固定视口壁纸，不再在长聊天 `#thread` 容器上重复铺满，降低画面放大模糊风险。蒙层浓度可另调。
- **表情头像库：** 两个角色各十槽，图片上传/删除/导出/导入都在本机扩展中。
- **纪念日：** 可以填写 YYYY-MM-DD，填写当天计为第 1 天；默认**不填写**。
- **AI 亲笔状态：** 默认关闭。需要时可参考 [可选协议教程](AUTHORED_STATE_CN.md)，协议是 `DUO_SKIN_STATE_V1`，不是私人脚本的旧协议。

## 从旧脚本升级

这是**公共独立版**，使用 `cds.public.v1.*` 存储，和私人测试版的 jdw 系列配置刻意隔离。**不会读取或自动迁移私人版头像、壁纸、纪念日**。请手动上传头像、选择壁纸。如需迁移私人图片，请自行导出并妥善保管头像库 JSON，严禁公开上传。

如果从**公共桌面版**迁移，脚本共享公用设置字段，但设备上的 Tampermonkey 存储不会自动云同步，仍需自行配置。

## 故障排查

- **没有小土星：** 确认 Firefox 扩展已启用、脚本匹配域名、完整关闭并重新打开 ChatGPT 标签页。
- **多个浮层或空白：** 排查是否同时启用了两份换肤脚本；在土星的高级工具中点「重新识别」，必要时停用再启用。
- **菜单文字变淡或打不开：** 检查是否与其他 CSS/插件冲突，试着暂停所有其他美化脚本。ChatGPT 更新页面 DOM 时可能需要等待修复。
- **壁纸看起来放大：** 确认使用当前公共手机脚本，聊天 `#thread` 不应再重复绘制 `cover` 壁纸。
- **诊断：** 小土星 → 高级工具与诊断 → 复制匿名诊断；报告时不要附带私人对话、登录信息、原始开发者控制台日志或头像库 JSON。
