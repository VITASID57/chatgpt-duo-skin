# ✍️ 附加玩法：让你的 GPT 亲自设计双人状态卡

这是一项**完全可选**的 Desktop Beta 功能。只装脚本就已经能使用本地自动头像和状态卡，不需要下面这些指令。

## 适用情景与安全边界

开启后，AI 可根据**刚才这一轮对话**为左右两张卡片选择已上传的表情、短句、花字和渐变。**它并不能读取浏览器里实际储存了哪些照片**：它只知道固定槽位 ID，所以未上传的表情会回退到默认头像。

这项功能**不会发送 API 请求**。但是 AI 必须将协议行写在**真实聊天回复**中，浏览器只是装饰/隐藏它。关闭脚本、切换到原生手机 App、分享原始聊天记录或复制原生全文时，**JSON 可能直接露出来**。因此：只在明确想使用它的窗口开启；不要写进全局自定义指令、长期记忆或所有聊天通用的 Skill。

## 1. 浏览器设置

打开小土星 → 身份与状态栏 → 开启 **「AI 亲笔状态优先」**。如果 AI 未给协议，仍使用本地自动状态。

## 2. 给自己的 AI 的简短指令（复制到想玩的聊天）

> 这段聊天启用 ChatGPT Duo Skin 的“AI 亲笔状态”。请正常回答我的问题，并在每次回答末尾另起一个**独立普通文本段落**，输出以 `DUO_SKIN_STATE_V1:` 开头的一整行合法 JSON，不加代码围栏或解释。由你按当前上下文即兴创作我的左侧/右侧双人状态卡：自行挑 `assistantAvatar`、`userAvatar` 表情槽，写两条不复读的助手状态、两条用户状态，以及 2–5 个颜色构成的渐变。正文不要被 JSON 取代。无法确定时选 `default`，不要捏造生理读数。若我说「停止亲笔状态」，立即停止输出该行。

以下是**格式示例**，不要逐字复制文案：

```text
DUO_SKIN_STATE_V1:{"protocol":"duo-skin-state/v1","mood":"happy","assistantAvatar":"joy","userAvatar":"play","status":["🎉 好消息：今天格外亮","🌈 喜悦光谱：多添了一层颜色"],"note":"A bright little orbit.","gradient":["#2E427F","#745AB6","#E59DCE"],"ink":"#FFFFFF","userCard":{"status":["🌷 心情纸条：带着笑意","✨ 好奇火花：仍在跳动"],"note":"Your little corner of the sky.","gradient":["#FFE1EF","#F49FCB"],"ink":"#3D2041"}}
```

如果不需要用户卡片的亲笔文本，可以省略 `userCard`。缺省时由本地脚本生成。无需写额外字段。

## 3. 协议字段（让不同 GPT 都能用）

| 字段 | 含义 | 规则 |
|---|---|---|
| `protocol` | 固定版本 | 必须是 `duo-skin-state/v1` |
| `mood` | 兼容情绪 | `night` / `work` / `happy` / `anger` / `soothe` / `worried` / `affection` / `play` / `curious` |
| `assistantAvatar`、`userAvatar` | 双方头像槽位 | 各选 `default` / `joy` / `play` / `work` / `anger` / `surprise` / `shy` / `affection` / `soothe` / `sleepy` |
| `status` | AI 卡片短句 | 恰好两个非空字符串，尽量短，有变化 |
| `note` | AI 卡片花字 | 一句简短英文/中文 |
| `gradient` | AI 卡片背景渐变 | 2 至 5 个 `#RRGGBB` 色值 |
| `ink` / `border` | AI 卡片字体/边框 | 可选 `#RRGGBB`；浏览器会检查对比度 |
| `userCard` | 右侧用户卡的可选亲笔覆盖 | 可包含 `status`（两句）、`note`、`gradient`、`ink`、`border` |

浏览器工作顺序：用户发消息后先生成本地右侧卡；助手回复后若有合法 `userCard`，会尝试覆盖最近上一条用户卡，**不改变原始发送消息**。时间快照由浏览器记录，不让 AI 随意伪造历史时间。

## 4. 关闭玩法

在那个聊天里对 AI 说「**停止亲笔状态**」，并关闭小土星里的「AI 亲笔状态优先」。单独关闭网页开关**不能通知 AI 停止输出 JSON**，两边要分别关闭。切换到官方 App 前尤其注意。

## 5. 给想二改的开发者

请保留独立的普通文本标记行和 JSON 校验，不要用不可信消息内容当 HTML 执行。状态颜色需做对比度验证；普通句子、引用里的示例、用户消息或代码块不应触发真实状态覆盖。当前协议是可选展示数据，**不等于能读取 AI 内在情绪**。
