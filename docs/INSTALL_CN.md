# 安装 · Desktop Beta v0.2.0

**支持：Windows 10/11、Chrome 桌面版、Tampermonkey、chatgpt.com。** 安卓 Firefox 版本另行开发，当前请勿把桌面测试当作安卓支持承诺。

## 首次安装

1. 打开 [Tampermonkey 官网](https://www.tampermonkey.net/) 安装 Chrome 扩展。
2. Chrome 地址栏输入 `chrome://extensions`，找到篡改猴 →「详情」→ 开启**允许用户脚本 / Allow User Scripts**。必要时检查 Chrome 扩展权限。
3. 打开仓库的 [`dist/chatgpt-duo-skin.user.js`](../dist/chatgpt-duo-skin.user.js)，复制全部源码。
4. 篡改猴 →「新建用户脚本」→ 全选替换示例代码 → 粘贴脚本 → `Ctrl+S` 保存，确认开关为开启。
5. 用 Chrome 打开 `https://chatgpt.com/` 任意已有对话，按 `Ctrl+Shift+R` 刷新。
6. 右下角出现小土星后，展开主题工坊，上传头像和壁纸、选择配色、设置双方昵称和可选纪念日。

**公共版不会携带任何私人头像、固定恋爱日期或专属角色名字。** 请自行配置。

## 从公共 v0.1.0 升级

在篡改猴里先备份原 v0.1.0，保持只有一条公共主题脚本，再替换为 v0.2.0。存储前缀 `cds.public.v1.*` 不变：原先的头像、壁纸、配色和昵称会尽可能沿用；新增表情柜初始为空。

**私人版并非公共版的直接升级路径**：两边本地存储刻意隔离，避免私人照片随任何公共脚本被读取。不要同时开启两套。

## 功能与设置

- 主题色：极夜深海蓝、暮紫星云、芭比玫粉、自定义主题；极夜深海蓝不可删除。
- 身份与状态栏：双方昵称、头像、每条消息大卡片、双方表情柜（每人十个槽）。
- 双人气泡：逐段独立 / 整条一颗 / 原生样式；逐段模式下普通文字可按标点智能分视觉气泡，发送给模型的仍是一整条原生消息。
- 全站背景：上传壁纸，调节奶白蒙层百分比。蒙层不会降低文本本身的不透明度。
- AI 亲笔状态：**选装玩法，默认关闭**。只有用户自己在指定聊天启用协议时才需要 AI 输出状态数据。详见 [进阶教程](AUTHORED_STATE_CN.md)。

## 故障排查

1. 没变化：确认篡改猴启用、Chrome 允许用户脚本、匹配 `chatgpt.com`，刷新。
2. 头像未变：确认在正确身份槽上传，图片能在设置面板预览；无匹配表情时会回退默认图。
3. 气泡互相遮挡：先暂停本脚本并恢复，再确保没有第二份换肤脚本同时运行；刷新后重试。
4. 壁纸只有一小块：调整白底蒙层；必要时使用高级工具里“点选白底”，不要选中代码块或输入框。
5. 状态栏变成一行 JSON：确认你是否在聊天里要求 AI 输出 `DUO_SKIN_STATE_V1`，并检查网页脚本是否运行；官方 App 没有对应隐藏功能。停止该窗口协议输出即可。
6. ChatGPT 页面改版导致定位失败：用土星菜单复制匿名诊断，在 [GitHub Issues](https://github.com/VITASID57/chatgpt-duo-skin/issues) 报告，不要贴聊天原文。

## 关闭与卸载

在篡改猴中关闭这条脚本即可恢复原生网页外观。关闭不清空数据；若要清理，还需要在扩展存储中删除以 `cds.public.v1.` 开头的对应配置。**头像库导出的 JSON 含实际图片，属于私人备份，切勿上传公开仓库。**
