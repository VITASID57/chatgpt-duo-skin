# 隐私与安全

ChatGPT Duo Skin 是运行在浏览器内的用户脚本，功能是修改 ChatGPT 网页外观。因需要识别消息角色及内容，脚本**技术上能读取当前网页 DOM**，包括正在显示的文本。请只安装来自你信任的来源并自己审阅源码。

- **不发送到作者服务器**：公共版本没有用于聊天收集、云端同步、埋点分析或图片上传的网络请求；头像和壁纸会被压缩并保存在 Tampermonkey 扩展本地存储。
- **本地元数据**：主题、昵称、可选纪念日起点、表情槽位、消息时间快照、较短的自动/亲笔状态文案、选中表情等都会存放在扩展设置中。我们不会在项目服务端读取它们。
- **AI 亲笔扩展**：它不是隐藏的私有 API 通道。启用者会要求 AI 在真实回答后面附一行 `DUO_SKIN_STATE_V1:` JSON。浏览器会尝试从显示层隐藏，但是复制原文、共享记录或进入未装脚本的 App 时可能露出 JSON。它也可能包含模型根据对话改写的文字，因此不要把秘密写入元数据。
- **文件分享警告**：导出的头像库 JSON 中有实际 Base64 图片；不要上传公开 GitHub Issue、讨论区或小红书附件。
- **停止与删除**：暂停/卸载用户脚本可以恢复网页外观，但不会自动清除 Tampermonkey 已存的个人设置。请自行在扩展的数据管理里删除以 `cds.public.v1.` 为前缀的公共主题数据。
- **兼容风险**：ChatGPT 会改变 DOM，脚本可能因结构更新错位、遮罩或无法识别。强制刷新、确认没有双脚本冲突后仍无效，可提交不含私密内容的匿名诊断。

本项目为非官方社区作品，与 OpenAI 无隶属或认可关系。
