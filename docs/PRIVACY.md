# Privacy & Security | 隐私与安全

**运行范围**：脚本只匹配 `https://chatgpt.com/*` 和 `https://chat.openai.com/*`。

**权限**：Tampermonkey 的 `GM_getValue`、`GM_setValue`。脚本通过读取页面 DOM 获取用户/助手消息位置和少量可见文字，以便呈现气泡并推断状态卡片文案。

**保存内容**：用户主动上传的头像、壁纸图片的 Base64 编码，名字、调色板、透明度及面板位置；每轮状态栏的首次本地观察时间、短状态文本和消息键。**脚本不专门保存聊天全文**。本地浏览器扩展存储可能被浏览器备份/同步，具体视用户设备和扩展设置而定。

**网络**：公开版源码中不调用 `fetch`、`XMLHttpRequest`、`WebSocket`、远程图床、第三方分析服务或 API 来上传聊天数据。`@match` 不等于脚本无法读取敏感内容：脚本拥有读取运行网页 DOM 的能力，请仅安装可信副本。

**与私人版隔离**：以 `cds.public.v1.*` 为公共版存储前缀，不读取任何旧私人版的键值。附带的 AI / ME 默认头像为新绘制中性图案，不含人像。

**卸载**：关闭脚本后停止修改页面；如需移除已存头像等，还应删除 Tampermonkey 对该脚本的存储数据。

**兼容性**：ChatGPT 非公开 DOM 可能调整；请先禁用其他 ChatGPT UI 扩展，再排查。不要在公开 Issue 中贴聊天正文、敏感截图或包含 Token 的日志。
